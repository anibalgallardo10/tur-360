# TUR 360 · tur-360.com

Página web de TUR, tours virtuales 360° en Caracas, Venezuela y Costa Rica.

- `index.html`: la página completa (ES / EN / PT / 中文).
- `img/`, `logos/`, `team/`: imágenes, logos de clientes y fotos del equipo.
- `CNAME`: dominio personalizado para GitHub Pages.

Formulario: los mensajes llegan a tur.acelerador@gmail.com vía FormSubmit (requiere activación única desde ese correo).
